# AI & ML Lab (24CSP503)

Lab experiments as Jupyter notebooks, numbered in syllabus order. Each notebook has numbered steps with explanations, code, executed outputs and a documentation summary.

| Exp | Notebook | Topic | Dataset |
|---|---|---|---|
| 1 | `24CSP503_Exp1_DataPreprocessing.ipynb` | Data preprocessing and data analysis | `employee_dataset.csv` |
| 2 | `24CSP503_Exp2_BFS_DFS.ipynb` | BFS and DFS algorithms | graph and maze in the notebook |
| 3 | `24CSP503_Exp3_UniformCostSearch.ipynb` | Uniform Cost Search | Romania road map in the notebook |
| 4 | `24CSP503_Exp4_AStar.ipynb` | A* algorithm | Romania road map and grid in the notebook |
| 5 | `24CSP503_Exp5_LinearLogisticRegression.ipynb` | (i) Multiple linear regression (ii) Logistic regression | `house_prices.csv`, `student_admission.csv` |

| 7 | `24CSP503_Exp7_DecisionTree_ID3.ipynb` | Decision tree (ID3) | `play_tennis.csv` |
| 8 | `24CSP503_Exp8_RandomForest_Boosting.ipynb` | (i) Random forest (ii) Boosting | `breast_cancer.csv` |
| 9 | `24CSP503_Exp9_NaiveBayes.ipynb` | Naive Bayesian classifier | `diabetes.csv` |
| 10 | `24CSP503_Exp10_KMeans.ipynb` | k-Means clustering | `mall_customers.csv` |
